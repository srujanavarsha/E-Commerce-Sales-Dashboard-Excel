# E-Commerce Sales Dashboard

## 📊 Project Overview

This project is an interactive E-Commerce Sales Dashboard created using Microsoft Excel. The dashboard helps analyze sales performance across different regions, products, months, and order statuses.

The project demonstrates data analysis, visualization, KPI tracking, and business insight generation using Excel.

---

## 🎯 Business Objective

The objective of this project is to analyze E-Commerce sales data and provide insights that can support better business decision-making.

---

## 📈 Key Performance Indicators

- Total Sales: ₹911,500
- Total Orders: 20
- Average Order Value: ₹45,575

---

## 📊 Dashboard Analysis

The dashboard includes:

- Sales by Region
- Sales by Product
- Monthly Sales Trend
- Order Status Distribution
- Interactive Month Slicer
- Interactive Region Slicer
- Interactive Product Slicer

---

## 💡 Key Business Insights

- South region generated the highest sales.
- Laptop is the top-performing product.
- Sales showed significant growth from February to May.
- Most orders were successfully delivered.
